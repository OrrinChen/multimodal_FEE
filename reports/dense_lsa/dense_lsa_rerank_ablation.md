## Setup

- Tasks: `60`
- Corpus mode: `benchmark`
- Documents: `320`
- Task set: `phase6_seed_multimodal_due_diligence`
- top_k: `5`
- Rerank candidate pool: up to `30` positive-score hits (`top_k * 6`)
- Provider: `corpus-tfidf-svd-subspace-v1`
- Embedding: Sublinear TF-IDF fit on benchmark document text only, then a 15-step subspace iteration toward the leading right singular vectors. Query and document vectors are the L2-normalized projections, rounded to 8 decimal places. This is not a LAPACK SVD and not a neural embedding.
- TF: `1 + ln(term_count) for term_count > 0`
- IDF: `ln((document_count + 1) / (document_frequency + 1)) + 1`
- Requested dimension: `32`
- Fitted dimension: `32`
- Vocabulary size: `201`
- max_features: `2000`
- min_df: `2`
- Subspace iterations: `15`
- Dense proxy reference: `deterministic-token-v1` dimension `64`
- Reranker: MetadataBoostReranker adds company +0.15, fiscal period +0.15, allowed source type +0.12, and metric +0.12 to the base retrieval score inside the positive-score candidate pool, then truncates to top_k.
- Corpus: Same constructed benchmark corpus as the published verdict benchmark: gold evidence specifications plus known distractors. Claim text is copied into both gold and distractor document text.
- Implementation: Pure Python float arithmetic. No BLAS and no neural model.

This ablation does not report verdict accuracy, numeric correctness, contradiction detection, unsupported-claim rate, answer faithfulness, memo usefulness, latency, or cost. Predictions are marked not_scored. The published full-engine 83.3% and BM25 66.7% figures are verdict accuracies from the existing benchmark, not outputs of this run.

evidence_recall_at_1 is the same ranked list cut to the first hit. It is a second cutoff, not a separate retrieval system. Recall@5 can sit near the ceiling because top_k is 5 and the task set has 200 gold evidence rows across 60 tasks.

Citation exactness equals evidence recall in this run because every retrieved row is marked cited.

## Method notes

- `bm25`: BM25EvidenceRetriever, top_k=5, no metadata rerank. Same retriever class as the published BM25 verdict baseline.
- `bm25_metadata_rerank`: BM25 scores on up to 30 positive-score candidates, then MetadataBoostReranker, truncated to top_k=5. Boosts are added to raw BM25 scores.
- `dense_proxy`: Existing DeterministicTokenEmbeddingProvider dimension 64: one hashed bucket per token, no IDF. Offline dense proxy, not a neural embedding, and not the published 66.7% verdict accuracy.
- `dense_lsa`: Cosine over corpus TF-IDF singular vectors, dimension requested 32, 15 subspace iterations, no metadata rerank.
- `dense_lsa_metadata_rerank`: Same TF-IDF singular-vector cosine scores on up to 30 candidates, then MetadataBoostReranker, truncated to top_k. Boosts are added to cosine scores.
